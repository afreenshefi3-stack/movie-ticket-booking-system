## Movie Ticket Booking System

Multi-screen JavaFX desktop application built with Java, applying OOP principles throughout.

### Features
- Login, Movie Selection, Seat Picker, and Booking Confirmation screens
- Real-time seat state management (Available / Selected / Booked)
- Dynamic pricing calculation and unique booking ID generation
- MVC separation with event-driven architecture

### Tech Stack
Java · JavaFX · Object-Oriented Design
